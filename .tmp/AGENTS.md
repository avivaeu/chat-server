# AGENTS

## Repository Purpose
This repository manages the deployment and operations of the Aviva Element Server Suite (ESS) chat server infrastructure.

## Environment
- Primary domain: `chat.avivaeu.org`
- Hosting provider: Hetzner
- Platform scope: ESS server deployment and related infrastructure configuration

## Organization Context
This deployment is maintained for the Aviva organization and is whitelisted/re-branded for the Aviva Church community (`avivaeu.org`).

## Notes for Future Agents
Treat this repository as infrastructure/operations code for the Aviva chat platform, not as a general application codebase.
See `README.md` and `infra/ess/README.md` for operator-facing details.
